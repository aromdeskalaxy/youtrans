# YouTrans

[English](README.md) · [สัญญาอนุญาต MIT](LICENSE)

YouTrans เป็นส่วนขยาย Chrome สำหรับเรียนภาษาจาก YouTube โดยแสดงซับหลักพร้อมซับรอง ชี้คำเพื่อดูคำแปล คลิกเพื่อฟังซ้ำ และเก็บคำไว้ในสมุดทบทวนได้

## ติดตั้งจาก GitHub

ใช้ Chrome บนคอมพิวเตอร์เวอร์ชัน 138 ขึ้นไปและวิดีโอ YouTube ที่มีซับ

1. กด **Code → Download ZIP** ที่หน้าโปรเจกต์ แล้วแตกไฟล์ หรือโคลน repository
2. เปิด `chrome://extensions` แล้วเปิด **Developer mode**
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์ที่มีไฟล์ `manifest.json`
4. เปิดหรือรีเฟรชหน้าวิดีโอ YouTube

โหลดจากซอร์สได้ทันทีโดยไม่ต้องบิลด์หรือติดตั้งแพ็กเกจ เมื่อต้องการอัปเดต ให้แทนที่ไฟล์ในโฟลเดอร์เดิม กด **Reload** ที่การ์ด YouTrans แล้วรีเฟรชหน้า YouTube การอัปเดตด้วยวิธีนี้เก็บสมุดและการตั้งค่าไว้ในโปรไฟล์เดิม

## ใช้งาน

| วิธีใช้ | ผลลัพธ์ |
| --- | --- |
| กดปุ่มคู่ภาษา ซึ่งเริ่มต้นเป็น **EN + ไทย** | เปิดหรือปิดซับสองภาษาสำหรับคลิปนี้ YouTrans จำสถานะแยกตามคลิป และคลิปใหม่เริ่มแบบปิด |
| กด **⚙** | เลือก **ภาษาหลัก** และ **ภาษารอง** แล้วกด **บันทึกคลิปนี้** หรือ **ใช้เป็นค่าเริ่มต้น** คู่ภาษาที่บันทึกเฉพาะคลิปมีผลก่อนค่าเริ่มต้น |
| ชี้คำในซับหลัก | ไฮไลต์คำหรือวลีที่จับคู่ได้ในซับรอง |
| คลิกคำในซับหลัก | ย้อนกลับไปช่วงที่คำนั้นขึ้นแล้วเล่นต่อ |
| **Alt + คลิก** หรือ **Option + คลิก** บน Mac | บันทึกคำ คำแปลเมื่อมี ประโยค และเวลาในคลิป |
| กดไอคอนบุ๊กมาร์กบนวิดีโอหรือไอคอน YouTrans บนแถบ Chrome | เปิดสมุดทบทวนเพื่อค้นหา ลบคำ หรือกลับไปเปิดคลิป ณ เวลาที่บันทึก |

ภาษาหลักมาจากแทร็กซับของคลิป ถ้าภาษาที่ตั้งไว้ไม่มีในคลิป YouTrans จะเลือกจากแทร็กที่มี ภาษารองใช้ซับ YouTube ก่อน หากไม่มีหรือโหลดไม่ได้ จะลองใช้ [Chrome Translator](https://developer.chrome.com/docs/ai/translator-api) สำหรับคู่ภาษาที่รองรับ หาก Chrome ต้องดาวน์โหลดโมเดล ให้กด **เตรียมตัวแปล**

การไฮไลต์เป็นการจับคู่โดยประมาณ การฟังซ้ำอิงเวลาที่คำปรากฏในซับ คำที่ขึ้นพร้อมกันจึงอาจย้อนกลับไปจุดเดียวกัน

## ข้อมูลและสิทธิ์ที่ใช้

YouTrans อ่านซับจากตัวเล่นบน `www.youtube.com` และโหลดแทร็กซับรองจาก YouTube เมื่อต้องใช้ Chrome Translator การแปลจะทำบนอุปกรณ์ โดย Chrome อาจดาวน์โหลดโมเดลเมื่อใช้ครั้งแรก

สิทธิ์ `storage` ใช้เก็บคู่ภาษา สถานะเปิดปิดต่อคลิป และสมุดทบทวนในโปรไฟล์ Chrome เครื่องนั้นผ่าน `chrome.storage.local` ส่วนขยายไม่มีเซิร์ฟเวอร์ของโครงการ ระบบติดตามการใช้งาน หรือบัญชีผู้ใช้ ลบคำทีละรายการได้จากสมุด หรือถอนการติดตั้งเพื่อเอาข้อมูลที่ส่วนขยายบันทึกไว้ออกทั้งหมด

## ร่วมพัฒนาและนำไปใช้ต่อ

โหลดโฟลเดอร์ซอร์สแบบ unpacked แล้วกด **Reload** หลังแก้โค้ด หากรายงานบั๊ก ให้ระบุเวอร์ชัน Chrome ลิงก์คลิปพร้อมเวลา คู่ภาษา และขั้นตอนทำซ้ำ อ่านกติกาอัปเดตเวอร์ชันได้ใน [AGENTS.md](AGENTS.md)

ใช้ ดัดแปลง และแจกจ่ายต่อได้ รวมถึงใช้เชิงพาณิชย์ ภายใต้ [สัญญาอนุญาต MIT](LICENSE) โดยคงข้อความลิขสิทธิ์และสัญญาอนุญาตไว้ YouTrans เป็นโครงการอิสระ และสัญญาอนุญาตนี้ครอบคลุมไฟล์ของโครงการ
